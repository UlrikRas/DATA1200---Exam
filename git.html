What is Git

Git i a distributed version control system. It was developed in 2005 by Linus Torvalds and was originally created to assist in the development of the Linux kernel. Just like Linux it's an open source project which is actively maintained. Its main use is controlling the source code of a program while developing software in collaboration with others. Git pioneered the branching model for source control systems. Practicing development with this model means you have a main branch of code, sometimes refered to as the "trunk" or master branch
